# Development status

AION is an unreleased local-development prototype undergoing security containment. Phase 1 intentionally disables remote control, remote screen access, arbitrary CLI execution, and update installation while secure replacements are designed. The intended product behavior is in [the master specification](AION_MASTER_SPEC.md); current verified status and gaps are in [the requirements traceability matrix](REQUIREMENTS_TRACEABILITY.md).

Documentation and screenshots must describe only verified behavior. See [the asset manifest](assets/ASSET_MANIFEST.md) for the release documentation gate.
